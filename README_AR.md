# DEGHEIDY Chatbot V10 — منع تكرار الصوت + إملاء عربي/English تلقائي

النسخة دي بتعالج أسباب محددة للتكرار في V9 بدل ما تستبدل اسم الموديل فقط.

## التغييرات الأساسية

1. **محرك صوت مختلف:** `faster-whisper` مع Whisper `large-v3` لما GPU متاح؛ `small` مع CPU لو GPU غير متاح. الموديلين بيكتشفوا اللغة تلقائيًا. تغيير المحرك لا يضمن إنه هيكون أدق في كل لهجة وكل جملة code-switching؛ لازم نقارن على نفس الصوت.
2. **لا إعادة للمقطع الصوتي القديم:** V9 كانت تعيد تفريغ ثوانٍ متداخلة. V10 بتثبت كل قطعة متكاملة مرة واحدة بعد سكون قصير. الفريمات نفسها لا تُستخدم في قطعة تالية.
3. **نص مؤقت بدل نص مكرر:** أثناء الكلام بتشوف معاينة قابلة للتعديل آليًا، وبعد الوقفة يتم استبدالها بالنص النهائي. المعاينة مش بتتضاف للنص النهائي مرتين.
4. **VAD:** WebRTC Voice Activity Detection لتجنب تفريغ الصمت وإعادة كلام قديم على أجزاء صوتية صامتة. Whisper يستخدم فلترة صمت إضافية ولا يعتمد على النص السابق (`condition_on_previous_text=False`).
5. **CPU voice-only:** حتى لو Colab قفل GPU، تقدر تحول الكلام إلى نص باستخدام CPU؛ زر Send للشات بيبقى معطل لأن Qwen3 Chat محتاج GPU. CPU بيبقى أبطأ وأقل دقة غالبًا بسبب النموذج الأصغر.
6. **تعديلات دردشة:** تجنب عرض قوائم تعليمات داخل الرد، وإظهار مسودة الرد بوضوح لحد ما فحص الجودة يخلص. ليست ضمانًا للصحة.

## التشغيل

- حمّل الـNotebook المرفق؛ افتحه في Google Colab ثم اضغط تشغيل الخلية الوحيدة.
- لو عندك GPU: Runtime → Change runtime type → T4 GPU. يبدأ Qwen3 4B ومع الصوت موديل Whisper large-v3 لو الذاكرة تسمح؛ لو تحميل الصوت فشل يحاول `medium` ثم `small`.
- لو GPU غير متاح: شغّل على CPU، هتشتغل واجهة الصوت بموديل Whisper `small` (عند أول تسجيل)، بينما محادثة Qwen هتكون معطلة.
- افتح رابط `https://...gradio.live` في تبويب Chrome مستقل، واسمح بالميكروفون.
- افتح **🎙️ كلام مباشر → نص**، اضغط الميكروفون واتكلم عربي وإنجليزي من غير اختيار لغة؛ راجع Ask ?? قبل الإرسال.
- لو التفريغ المباشر متأخر، جرب قسم **تسجيل/ملف كامل** للتعرف على الجودة بعيدًا عن التقطيع.
- في نهاية الشغل اختار Runtime → Disconnect and delete runtime لتوفير الموارد. لا تشارك رابط Gradio العام.

## القيود والتشخيص

- النموذج يتعرف على اللغتين دون أن تختار لغة، لكن مش مضمون يكتب كل لفظ إنجليزي بحروف لاتينية داخل جملة مصرية؛ دي مشكلة فعلية في كثير من أنظمة ASR.
- الكتابة متجددة **كل بضعة ثوانٍ تقريبًا**، مش كل حرف لحظيًا. سرعة النسخة بتتأثر بالـGPU/CPU، وطول الكلام، وشبكة Colab.
- جودة الصوت تعتمد على الميكروفون، والمسافة، والضوضاء؛ وفي حالة الشك جرّب تسجيل ملف وإرساله للتفريغ الكامل.
- الجهاز المحتاج GPU ممكن يرفض الاتصال بسبب الحصة؛ لا يوجد كود يفتح حصة GPU المغلقة.
- لو V10 غير دقيقة، اختبرها على 10 جمل صوتية محفوظة وقارنها بنفس الجمل في V9 باستخدام WER/CER وقائمة أخطاء English terms، قبل ما نستنتج إنها أفضل.
- الكلام بيعدّي على صفحة Gradio المؤقتة وجلسة Colab، مش بيتم تشغيله كليًا داخل المتصفح.
- **الاختبارات**: `python -m unittest discover -s tests -v` (اختبارات تصميم وسلوك محاكاة؛ ليست Benchmark صوتي للموديلات الحقيقية).

## خصوصية وحقوق

موديل المحادثة Qwen وWhisper لهم تراخيص مستقلة حسب النموذج. رابط المشاركة المؤقت يتيح الوصول للواجهة؛ لا تشاركه، ولا تستخدم تسجيلات خاصة بدون موافقة أصحابها.
